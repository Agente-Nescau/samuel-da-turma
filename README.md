# Mural da Turma

Mural colaborativo da turma do 1º ano do **Curso Técnico de Informática para a Internet**, disciplina **Versionamento e Colaboração**.

Cada aluno contribui com um cartão de apresentação na pasta [`alunos`](alunos/) usando **fork** e **Pull Request**, do mesmo jeito que se contribui com projetos abertos no mundo real.

## Quero colocar meu cartão

Leia o [**CONTRIBUTING.md**](CONTRIBUTING.md). Lá está o passo a passo completo.

## Como o mural funciona

1. Você faz um **fork** deste repositório.
2. No seu fork, cria a branch `mural/seu-usuario` e o arquivo `alunos/seu-usuario.md`.
3. Abre um **Pull Request** para este repositório.
4. O professor revisa e, se estiver tudo certo, faz o **merge**.
5. Seu cartão aparece na pasta `alunos`.

## Regras rápidas

- Um aluno, um arquivo. Não edite o cartão de ninguém.
- Este repositório é **público**: nada de dados pessoais.
- Respeito sempre. Veja as [regras de convivência](CONTRIBUTING.md#6-regras-de-convivência).
